# Breast-Cancer-with-Attention-Unet
## Dataset

This project uses the Breast Histopathology Images dataset.

Download dataset from:
https://www.kaggle.com/datasets/paultimothymooney/breast-histopathology-images

After downloading, place the dataset at:
data/IDC_regular_ps50_idx5/

Then build metadata:
python src/datasets/breast_cancer_dataframe.py
